# M1 requirement → test table

Scope: logos-co/rfp issue 171 (M1, core market primitives). Requirement numbers are RFP-008's (F = Functionality,
R = Reliability). Tests named `m1_core::*` are in `programs/argo_lending/integration_tests/tests/m1_core.rs` and run
the Argo guest and the pinned lez-programs v2.0.1 token in the in-process LEZ v0.2.4 state machine. `e2e` is
`./harness/localnet.sh e2e` (`harness/runner/src/bin/argo_m1_e2e.rs`) against the standalone sequencer.
`forged_input_tests::*` are in `programs/argo_lending/src/lib.rs`. All of these run in CI
(`.github/workflows/argo-ci.yml`).

| Requirement | What M1 delivers | Tests |
| --- | --- | --- |
| F1 singleton | One program holds every market; Config, Market, Position and the vaults are PDAs of it | `m1_core::two_markets_are_isolated` (two markets, one program, owners checked), `six_operations_end_to_end`, e2e |
| F2 immutability (and the admin it allows) | No upgrade, pause or market-edit path exists in the program; the only admin actions are Config-only LLTV/IRM enabling; only the genesis admin can initialise Config (D14) | `m1_core::only_genesis_admin_can_initialize`, `admin_operations_are_admin_only`. Immutability itself is structural: no instruction writes a Market's parameters after `create_market` (`argo_lending_core::Instruction`) |
| F3 permissionless markets, 5-param id | `create_market` by any signer; id = SHA-256 over 158 bytes; oracle param = descriptor digest (D2); enabled LLTV/IRM; feed must exist (D7); second create fails | `argo_lending_core` tests `market_id_preimage_is_158_bytes`, `market_id_changes_with_every_param` (all five), `oracle_digest_binds_account_and_max_age`; `m1_core::create_market_guards`, `create_market_more_guards` (IRM not enabled, more guards), e2e |
| F4 supply | Shares rounded against the supplier; payer must be a holding of the loan token | `m1_core::six_operations_end_to_end`, `share_denominated_supply_and_withdraw_round_against_the_user`, `wrong_token_holding_is_rejected`, `exactly_one_of_assets_and_shares`, e2e |
| F5 withdraw, subject to liquidity | Only `on_behalf` withdraws; shares burned rounded up; `total_borrow ≤ total_supply` | `m1_core::withdraw_beyond_liquidity_is_rejected`, `share_denominated_supply_and_withdraw_round_against_the_user` (shares burned rounded up), `withdraw_by_someone_else_is_rejected`, `unsigned_caller_is_rejected`, `over_withdraw_over_collateral_over_repay_are_rejected`, e2e |
| F6 collateral and borrow up to LLTV | `supply_collateral` (no accrual); `withdraw_collateral` checks health when there is debt; `borrow` checks health (rounding against the borrower) and liquidity | `m1_core::borrow_past_lltv_is_rejected`, `withdraw_collateral_that_breaks_health_is_rejected`, `borrow_beyond_liquidity_is_rejected`, `share_denominated_borrow_and_full_repay`, `other_users_position_is_rejected`, `operations_on_a_missing_position_are_rejected`; `argo_core` `health::tests::*`; e2e (over-LLTV borrow and unhealthy collateral withdrawal rejected, reason read from the sequencer log) |
| F7 repay, in full or partially | Anyone repays for `on_behalf`; shares burned rounded down, cost rounded up; Morpho `zeroFloorSub` on total debt | `m1_core::share_denominated_borrow_and_full_repay` (partial then full; hits zeroFloorSub), `six_operations_end_to_end`, `over_withdraw_over_collateral_over_repay_are_rejected`, e2e |
| F9 lazy accrual (scaffolding) | `last_update_ms` from CLOCK_01, forward only; rate 0 until M2 | `m1_core::accrual_moves_last_update_forward_only`, `clock_must_be_clock_01_and_started` |
| F13 / R1 oracle read | Exact price account, owner, pair, non-zero, `max_age_ms` (D5), future skew (D5a); Q64.64 | `m1_core::other_price_account_is_rejected`, `zero_or_wrong_pair_price_is_rejected`, `stale_price_blocks_borrow_but_not_debt_free_exit`, `future_dated_price_is_rejected`, `price_account_owner_and_quote_are_checked_on_read`; `external::tests::price_account_is_136_bytes_and_tolerates_trailing_bytes` |
| R6 no admin can block supply, withdraw, repay | There is no pause; admin instructions write Config only | structural (`admin.rs` writes only Config); `m1_core::admin_operations_are_admin_only` |
| R7 inflation resistance | Virtual shares, dead deposit, accounting not balance-based | `argo_core` `shares::tests::empty_market_first_deposit_is_not_100_percent` (empty market, math level), `non_exact_ratio_pins_floor_and_ceil`, proptests `up_is_down_or_down_plus_one`, `round_trips_favour_the_protocol`; `m1_core::donation_does_not_inflate_shares`, `near_empty_market_attacker_cannot_dilute_victim`, `supply_withdraw_rounding_loop_never_profits` |
| Custody (LP-0013 rule) | Vaults are token-program holdings under Argo seeds; every token call targets the pinned id; a vault id must be the market's PDA | `m1_core::vault_cannot_be_debited_directly` (forged vault debit against the v2.0.1 token), `own_holding_as_vault_is_rejected` (fake-vault substitution), `vendored_token_binary_has_the_pinned_program_id`; `external::tests::token_program_id_matches_published_hex`, `token_instruction_indices_match_upstream`, `token_account_types_match_v2_0_1`. Wrong PDA seed: M0 spike S-A A4 (the runtime's PDA check; Argo's own seeds are derived, not passed in) |
| Inputs the runtime cannot check (D15) | Every handler refuses unowned, non-default inputs; callers and admin must be program-owned | `forged_input_tests::*` (forged caller, payer, clock, admin; host-level), `m1_core::used_unowned_key_is_refused_by_the_runtime_check` (a key that has signed before, as caller and as payer, through the real runtime), `unowned_key_cannot_be_caller`, `receiver_not_owned_by_the_token_program_is_rejected` |
| Atomicity | A failed token leg reverts Argo's accounting | `m1_core::failed_token_leg_reverts_accounting`, `create_market_rolls_back_when_dead_deposit_fails`, e2e (market unchanged after each rejected transaction) |

Not in M1 (later milestones): liquidation and flash loans (M3), interest rate model, fee and admin scope including
LLTV removal (M2), manager authorisation F17 (M3), real oracle feeds and per-feed `max_age_ms` values (M4).
