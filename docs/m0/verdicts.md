# M0 spike verdicts

Each verdict quotes the `VERDICT` line printed by `spikes/run.sh S-X` on the
clean host, the commit it ran at, and the design consequence.

| Spike | Verdict | Run | Consequence for M1–M3 |
| --- | --- | --- | --- |
| S-A chained-call atomicity + re-entry | **GO** | hetzner2 2026-09-02 + CI, `cargo test -p spike_integration_tests --test spike_ab` (a1–a6 of 8 tests; `evidence/localnet/S-A.run.txt`) | Settlement as state-write + chained token legs is safe: a failing last leg reverted the state write and the token transfer (`ProgramExecutionFailed("Guest panicked: Internal asked to fail")`, all balances unchanged). Self re-entry works and a top-level call into the internal entrypoint is rejected, so `repay_flash` can be an internal self-call gated on `caller_program_id`. 10 chained calls (11 executions) accepted, 11 chained rejected (`MaxChainedCallsDepthExceeded`). Not done in M0: a sequencer-layer dropped-tx observation, a foreign-program debit attempt, and the explicit `InconsistentAccountPreState` negative (A7). |
| S-B custody rule | **GO** (builtin token) | same run (b1–b5; `evidence/localnet/S-B.run.txt`) | Vault = token-owned PDA claimed via chained `InitializeAccount` under Argo's seed; anyone credits it, only Argo debits it by seed. Wrong seed → `InvalidAccountAuthorization` (the same runtime check a foreign program would hit; a foreign-program guest was not built); signer-less debit → `Sender authorization is missing`; credit before claim → `ClaimedUnauthorizedAccount` and a later `Init` still succeeds, so `create_market` claims both vaults first. Test b5 confirms the `token` id the public testnet registered on 2026-09-02 equals the builtin image id these tests execute; the testnet also registers no `clock`/`ata`/`vault`, so M1 targets the builtin behind a `token_core` adapter and the accrual clock source is an M1 decision. |
| S-C event surface | **NO-GO** (as expected) | hetzner2 2026-09-02 + CI, `spikes/S-C/run.sh` | v0.2.4 `ProgramOutput` and `Block` have no event field (source), and `getTransaction` returns only `(the submitted LeeTransaction, block id)`, so no execution output of any kind reaches a client (`evidence/localnet/S-C-*.json`). Reference liquidator/monitor observe by PDA polling: 8.4–8.8 ms per `getAccount` on localhost (200 calls to one account; no multi-account sweep was measured, that is M4 work). Events landed on LEZ `dev` after v0.2.4 (PR 705/707, indexer `getEvents`); the observation layer sits behind a trait so M4 swaps to events when a tag ships them. |
| S-D compute budget | **GO** | hetzner2 2026-09-02 + CI, `spikes/S-D/run.sh` (`evidence/localnet/S-D.run.txt`) | Per-execution cycles (po2-padded, the runtime's own metric; 10k stress iterations trip `Session limit exceeded` as asserted): Argo supply-shaped leg 239k, builtin token Transfer 131k, Argo leg emitting one transfer + one self-call 271k, self-call leg 74k; that three-leg chain totals 476k. Arithmetic costs ~5.3k cycles per accrual/health/LIF-shaped iteration (bitwise 256/128 division), so a liquidation extrapolated as PayOut leg + 40 iterations + one more transfer is ~0.6M, under 2% of the 32M budget; M3 measures the real thing and M1 uses a cheaper widening divide. **Account size dominates**: carrying a state account through one execution costs 544k cycles at 1 KB, 4.8M at 10 KB, 23.7M at 50 KB (74% of budget), consistent with lez-programs' benchmark of ~33M for a 100 KB owned account. Every Argo account stays under 1 KB. |
| S-E fee within deshield | **PARTIAL** (design change established; linkability not evaluated) | hetzner2 2026-09-02 + CI, `spikes/S-E/run.sh`, wallet v0.2.4 vs local sequencer | v0.2.4 has no transaction fees, so "fund the fee inside the deshield" is vacuous today. The live rule: a deshield into a never-initialised public account is rejected by the privacy circuit (`Cannot claim unauthorized account`, saved in `evidence/localnet/S-E-e0b.wallet.txt`), so the SDK first initialises the ephemeral account with its own key (E0, public tx), then deshield (E1: A=300) → a public op signed by A (E2: native transfer A→B in M0) → reshield to a fresh private note (E3: A=0). Each step's wallet output and raw `getTransaction` are under `evidence/localnet/S-E-*`, and the script exits non-zero if any step deviates. E4 (which accounts co-appear with A in public block data) was NOT evaluated: raw blocks are saved but need a borsh decoder (M5). Re-test when fees land (PR 801). |
